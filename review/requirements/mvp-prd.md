# MVP PRD

**Users:** QR guests, waiters, kitchen/bar staff, admins. **Goal:** shorten table ordering and payment friction while keeping menu availability and POS handoff safe.

- QR opens a scoped table session; party size is editable.
- Guests browse pinned categories, see unavailable dishes, add items, review cart, request service, and pay via server-computed KES totals.
- Staff see floor, kitchen/bar tickets, live availability, payment reconciliation.
- Admins add/edit dishes, drinks, images, categories, sub-categories, station, price, and availability.
- Realtime: menu availability, table status, order status.
- v1 refunds are staff-recorded; no Daraja reversal automation.
