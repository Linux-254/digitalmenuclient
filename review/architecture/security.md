# Security Measures

RLS is mandatory; least-privilege roles; Google OAuth for staff; service-role keys server-only; unguessable QR/callback tokens; rate-limit session/payment initiation; idempotency keys and unique constraints; masked phones; generic client payment errors; no raw callback/credentials/full phone logs; outbound-only POS bridge; audit every payment transition and admin override; WAF/bot protection; CSP, secure headers, dependency scanning, backups, alerts, and dead-letter reconciliation.
