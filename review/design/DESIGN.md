# Design System
Forest-green editorial food poster meets operational SaaS. Display typography uses Georgia/serif for warmth and hierarchy; UI uses Inter/system sans for clarity. Use an 8px rhythm, warm paper surfaces, cream CTAs, lime status accents, 20px cards, 11px controls, and high-contrast focus states. Guest menu uses organic circles and horizontal category rails; staff uses dense panels and clear status color. Avoid motion that blocks ordering.
